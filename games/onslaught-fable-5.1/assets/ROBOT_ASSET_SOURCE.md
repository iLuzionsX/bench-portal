# Robot asset source

The live ONSLAUGHT enemy visual upgrade uses **Animated Robot** by **Quaternius**.

- Original listing: https://poly.pizza/m/QCm7qe9uNJ
- License on the original listing: Public Domain (CC0)
- Format used by the game: GLB / glTF 2.0
- Build-time download mirror: `age2pierre/solid-akkadi`
- Pinned mirror commit: `c6b4450c8738be1887f7b50415e30a9f642e5dc4`
- Mirror path: `demo-app/public/assets/Animated_Robot.glb`
- Expected downloaded size / GLB declared length: 401024 bytes
- Git blob SHA: `8784b36b4a174bfc89a31150b39f1d4fd1853dfa`

The model is downloaded during the GitHub Pages build into `assets/Animated_Robot.glb`. The build validates both the exact file size and the glTF binary header before packaging it.

The gameplay code, hitboxes, enemy health and AI remain ONSLAUGHT's own; the downloaded model replaces only the rendered enemy body.
